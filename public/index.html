Arrow Connections journey planner

Runs a multi-criteria Profile Connection Scan Algorithm — Pareto-optimal over arrival time and transfers, like planner.js — entirely in your browser, over one or more geospatially and temporally partitioned arrow-format datasets written by gtfs2lc. No server-side routing — see arrowconnections.md for the format this reads.

Advanced

Click the map to scan every selected network for how far it can be reached from that point within a chosen travel time — the same connection scan as the planner above, run one-to-many from a clicked stop-access point instead of one-to-one between two stops.
